# Source snapshots, provenance and corrections — Phase 0.0-E

## Immutable raw evidence

After an approved fetch, persist response bytes and safe metadata before any canonical mutation. Use DB metadata plus compressed content-addressed files, for example `raw/<provider>/<sha256-prefix>/<sha256>.json.gz`; file name is derived from SHA-256 of **uncompressed exact response bytes**, with canonical hash recorded in DB. Write temp file, fsync/atomic rename, then commit metadata; a crash before rename may leave a temporary file, while a crash after atomic rename but before metadata commit may leave an **unreferenced final content-addressed blob**. Neither is published canonical evidence until metadata commits. Cleanup scans both temporary and final unreferenced blobs only after a grace period and safe cross-check against committed metadata, in-flight writes and backups; never delete a blob still referenced by a published fact. Identical bytes deduplicate the blob; each retrieval still gets a separate immutable observation with UTC retrieval time, request fingerprint, HTTP status/content type, provider-reported timestamp if explicitly supplied, and run/item IDs. Request fingerprint omits secrets and normalizes only documented safe parameters; do not store cookies, API keys, authorization headers, token-bearing URLs or sensitive environment values.

Raw files are audit/replay input, **not** the application query layer. Canonical rows and source references serve UI/API. Retain snapshots and provenance for the audit/correction horizon permitted by actual provider rights; no fixed legal retention period is assumed. Backup DB metadata and blob store together, verify checksums/restorability, and clean unreferenced temp blobs only. A raw blob referenced by a published fact, issue, correction or audit is never garbage-collected silently. Any eventual deletion for rights/retention is documented, evidence-aware and may force coverage/publication downgrade.

## Replay and source links

`SourceRecordReference` points to snapshot ID plus stable provider record path/key (e.g., gamePk and raw atBatIndex), retrieval time and optional provider timestamp. It does not assert truth. `FactSourceLink` connects a source claim to a typed canonical fact with SUPPORTS, CONFLICTS, WITHDRAWN or UNRESOLVED; different snapshots may coexist. To replay: pin immutable bytes, parser version, mapping/config version and identity registry revision; parse/normalize; compare proposed claim set and canonical fingerprint; perform validation/coverage; publish a new dataset revision only on accepted changes. Replay results are deterministic for the same inputs and versions. Schema drift is an issue, not permission to silently drop fields.

## Corrections and tombstones

Compare checksums and normalized claim sets. A changed response is not automatically authoritative over every earlier field. A current schedule snapshot can correct present display state while preserving prior scheduled time as lifecycle history. A changed play/boxscore can propose a PA/HR correction only after full reconciliation; if it conflicts, quarantine and downgrade affected coverage. Never hard-delete a published fact merely because one subsequent response omits it. Absence is `MISSING_IN_NEW_SNAPSHOT` evidence, not a tombstone. Confirmed withdrawal requires explicit provider correction/delete signal or repeated corroborated evidence plus documented operator decision and source references. A withdrawn fact retains historical source links and correction trail, changes the current canonical projection by new revision, and invalidates affected analytics. If rights require physical removal, apply an externally approved deletion policy and mark resulting analytic coverage appropriately; do not pretend an audit trail remains complete.

Names and mutable venue metadata can change without changing IDs. GamePk continuity across sampled postponement/resumption is preserved. When a source ID changes or two identities collide, retain both raw claims and quarantine the merge. Timestamp order of retrieval is not a blanket truth order; category authority and explicit correction evidence govern reconciliation.
